# UI Context — Invoice & Billing System

## Theme
Modern, clean, premium business dashboard. Use a light interface with deep navy text, blue primary actions, neutral backgrounds and restrained accent colors. Maintain readable contrast and consistent spacing.

## Color Tokens
Define CSS custom properties and use them throughout instead of hardcoded colors:
- `--bg-base`: #f5f7fb
- `--bg-surface`: #ffffff
- `--text-primary`: #172033
- `--text-muted`: #64748b
- `--accent-primary`: #2563eb
- `--border-default`: #e2e8f0
- `--state-error`: #dc2626
- `--state-success`: #16a34a
- `--state-warning`: #d97706

## Typography
- Use a modern sans-serif font stack with clear hierarchy.
- Body text should be readable; labels and helper text should not be overly small.

## Components and Layout
- Responsive app shell with sidebar navigation and top bar.
- Dashboard cards for key metrics, recent invoices and quick actions.
- Tables with search, filters, pagination and empty/loading/error states.
- Forms with labels, helpful validation feedback and keyboard accessibility.
- Confirmation dialogs for destructive actions.
- Invoice preview should resemble a professional printable invoice.

## Navigation
- Dashboard
- Invoices
- Customers
- Products / Services
- Payments
- Reports
- Business Settings

## UX Rules
- Prioritize quick invoice creation and clear totals.
- Avoid unnecessary animations and decorative clutter.
- Show currency and tax breakdown explicitly, with configurable currency formatting.
- Responsive behavior should work on desktop, tablet and mobile widths.
- Use consistent button, form, table and modal patterns.

## Icons
Use a consistent accessible icon set if added. Icons should supplement labels, not replace them where clarity is needed.
